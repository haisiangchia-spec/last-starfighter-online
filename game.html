BUILD STATUS // RULEBOOK IMPLEMENTATION v4.0 · SEEDED BATTLES
Playable prototype with original-style movement, firing bases, 2d6 attacks, 36-result damage chart, energy, missiles, and scenario objectives. Missile ammunition is now consumed only when a valid shot is launched. The scanned rules are the reference. Enter a battle seed before NEW MISSION to replay the same dice and computer choices with the same orders. Built-in diagnostics include fleet-scale tests and Death Blossom power-boundary checks. Not yet a fully verified reproduction: some edge cases remain unverified: precise printed mapsheet hex positions, simultaneous damage effects, and original asteroid boundary conventions. Browser smoke tests cover both AI and hot-seat turn completion; multi-turn Swarm combat and full hot-seat fleet order entry have been browser-tested in earlier builds; full scenario completion under every outcome remains to be verified. These are identified in the help panel rather than silently presented as original rules.

PILOT'S FIELD MANUAL

Plot up to 5 forward hex movements (3 for Swarm ships). Left/right orders first move one hex forward, then rotate one hex-side. Maximum 3 turns. Holding position uses no power if you do not fire.

Normal movement and/or firing costs 1 power point per active turn, not per action. Recharge takes a full stationary, non-firing turn and restores 5 power (maximum 20). The Gunstar and Deck Fighter have 20 starting power points.

Weapons: standard laser base 3/range 10; Swarm laser base 4; particle base 4/range 9; photon base 5/range 8. Add one to the base per additional hex of distance. Roll 2d6 ≥ target number. Stationary targets −1; asteroid shooter/target +1 each. Photon blasts affect the target hex and six neighboring hexes in open space.

For damage, roll a red die for table 1–6 and white die for result 1–6. Particle shifts the table +1 (maximum 6), Swarm laser and missiles −1 (minimum 1). Fuselage arcs cascade into engine and targeting, and every second fuselage arc also affects vector control and powered systems.

Prototype limitations: Computer opposition uses an original heuristic rather than historical AI (the board game had no AI). Local two-player mode now requires each surviving ship on both sides to seal its own orders before resolution; conceal the screen when passing turns. Swarm deployment uses the rulebook’s two-wave spacing and facing, adapted to the digital map; exact printed hexes remain unverified. Use RUN DIAGNOSTICS to execute in-browser rules sanity checks; exceptional combinations remain under test. Death Blossom is a six-orientation weapon volley and consumes all power, but exact target allocation is automated.
